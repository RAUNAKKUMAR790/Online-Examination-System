IMPORTANT LIMITATIONS
- SMTP behavior was tested with an isolated mock transport to validate OTP flow, not to send real email.
- Live Gmail delivery, inbox/spam delivery, and the user's own Gmail App Password have NOT been verified.
- This is not a full browser click-through of every exam/admin workflow, a penetration test, or a production security audit.
- The project uses local JSON files and client-side pages; do not expose it publicly without reviewing authentication/session handling, authorization, HTTPS, rate limiting, backups, and data protection.
- .env and node_modules are intentionally excluded. Copy .env.example to .env and configure a Gmail App Password before testing real email.
- Existing server-data files are preserved; do not delete them if you want to retain the saved accounts.
